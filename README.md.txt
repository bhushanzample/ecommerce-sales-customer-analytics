 E-commerce Sales & Customer Analytics

Project Overview
This project focuses on analyzing e-commerce sales and customer data to understand business performance, sales trends, customer behavior, and profitability.

The project uses approximately 138,000 sales records to generate meaningful business insights.

 Tools & Technologies
- Microsoft Excel
- PostgreSQL (SQL)
- Power BI

 Project Objectives
- Analyze overall sales and revenue.
- Understand customer purchasing behavior.
- Identify top-performing products.
- Analyze monthly sales trends.
- Calculate important business KPIs.
- Track profit and profit margins.
- Analyze new and repeat customers.

 Project Workflow

 1. Excel
- Data cleaning and formatting.
- Data analysis using formulas.
- Pivot table analysis.
- Customer and sales segmentation.

 2. SQL (PostgreSQL)
- Data querying and analysis.
- Joins and subqueries.
- CTEs and window functions.
- Monthly sales analysis.
- KPI calculations and SQL views.

 3. Power BI
- Interactive dashboard development.
- KPI cards and visualizations.
- Sales performance analysis.
- Customer segmentation.
- Business insights and reporting.

 Key Performance Indicators (KPIs)
- Total Revenue
- Total Orders
- Total Customers
- Total Profit
- Profit Margin
- Average Order Value (AOV)
- Returned Orders
- Cancelled Orders

 Project Structure

- Excel: Data cleaning and analysis files.
- SQL: SQL queries and analysis.
- PowerBI: Interactive dashboard file.
